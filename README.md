# 価値観ランキング

2人で遊ぶ価値観当てゲーム。お題ごとに8つの選択肢から1〜3位を選び、3位から順に同時にめくって見せ合います。

**遊ぶ：** https://adachi-0518.github.io/kachikan-ranking/

## あそびかた

1. 2人とも自分のスマホで上のURLを開く
2. 最初の役を決める（片方は「答える人」、もう片方は「当てる人」）
3. 同じお題を選ぶ。お題には「No.12」のような番号があるので、番号を伝え合う。ランダムでもOK
4. 答える人は本音で、当てる人は相手の答えを予想して1〜3位をタップ
5. せーので 3位 → 2位 → 1位 の順にタップしてめくる
6. 理由を話して、当てた数を入れる。次のお題へ進むか、そこで終えて結果を見る

- お題は30問、6カテゴリ（もしも／旅・あそび／人生／恋愛・人間関係／仕事・お金／日常）
- 好きな順に1問ずつ遊べます。遊んだお題には「済」がつきます
- 役は1問ごとに自動で入れかわり、お題の画面でも切り替えられます
- 記録はそのスマホのブラウザに残ります。結果画面から消せます
- 結果画面に、ジャンル別の当たり率が出ます

## 相手の回答と見比べる（サーバーなし）

1. 結果画面の「回答を交換する」で「コードを送る」を押し、LINEなどで相手に送る
2. 相手も同じように自分のコードを送る
3. 送られてきたリンクを開く（またはコードを貼り付けて「読み込む」）
4. 2人とも遊んだお題について、お互いの順位が横に並ぶ。予想が当たった数は自動で数えられる

コードは `KR` で始まる英数字です（10問で70文字くらい）。中身は名前・お題の番号・役・選んだ順位・当たり数だけで、どこのサーバーにも送られません。

## お題を変えるには

`questions.js` を書き換えるだけです。1問につき選択肢は8個です。画面の番号は並び順で決まるので、新しいお題は末尾に足してください。

## デザイン

[デジタル庁デザインシステム](https://design.digital.go.jp/)の値を土台にしています。

- 書体は Noto Sans JP。本文は16px以上、行間1.7
- 主色は Blue-900（#0017c1）。淡い Blue と Solid Gray で面をつくる
- 線で区切らず、色の面（カード）で区切る。角丸はボタン8px、カード12〜20px
- フォーカスは黄色と黒の二重リング
- 生成AIで作ったように見えやすい要素は使わない：絵文字のアイコン、紫のグラデーション、斜線模様、紙吹雪、跳ねるアニメーション、意味のない小さなラベル

## ファイル

- `index.html` 画面の土台
- `style.css` 見た目
- `app.js` ゲームの動き
- `questions.js` お題
