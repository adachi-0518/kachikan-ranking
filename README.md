# 価値観ランキング

2人で遊ぶ価値観当てゲーム。お題ごとに8つの選択肢から1〜3位を選び、せーので3位から順にめくって見せ合います。

**遊ぶ：** https://adachi-0518.github.io/kachikan-ranking/

## あそびかた

1. 2人とも自分のスマホで上のURLを開く
2. 1問目の役を決める（片方は「答える人」、もう片方は「当てる人」）。2問目からは自動で交代
3. 答える人は本音で、当てる人は相手の答えを予想して1〜3位をタップ
4. せーので 3位 → 2位 → 1位 の順にタップしてめくる
5. 「なんでそれ選んだ？」で話して、当てた数を入れる
6. 6問終わると2人のシンクロ率が出る

## お題を変えるには

`questions.js` を書き換えるだけです。1問につき選択肢は8個です。

## デザイン

[デジタル庁デザインシステム](https://design.digital.go.jp/)の値を土台にしています。

- 書体は Noto Sans JP。本文は16px以上、行間1.7
- 主色は Blue-900（#0017c1）、文字と線は Solid Gray
- 角丸8pxのボタンと入力欄、フォーカスは黄色と黒の二重リング
- 生成AIで作ったように見えやすい要素は使っていない：絵文字のアイコン、ベージュ地、角丸カードの並び、斜線模様、紙吹雪、跳ねるアニメーション、「TALK」のような見出しの上の小さなラベル

## ファイル

- `index.html` 画面の土台
- `style.css` 見た目
- `app.js` ゲームの動き
- `questions.js` お題
